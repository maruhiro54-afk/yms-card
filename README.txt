GitHub Pages公開手順
1. GitHubで新規Publicリポジトリ yms-card を作成
2. このフォルダ内の index.html, front.png, back.png, contact.vcf をリポジトリのルートへアップロードしてCommit
3. Settings > Pages > Build and deployment > Deploy from a branch > main / (root) > Save
4. 数分後 https://ユーザー名.github.io/yms-card/ にアクセス
5. 公開URLをQRコード化。NFC購入後は同じURLを書き込む。

注意: GitHub Pagesで公開した連絡先はインターネット上で誰でも閲覧できます。
